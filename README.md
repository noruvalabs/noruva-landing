# Noruva Labs Landing

Astro + React landing site for Noruva Labs — Interview Assistant, Immigration Assistant, Law Assistant, and custom agentic AI services.

## Commands

| Command | Action |
| :--- | :--- |
| `npm install` | Install dependencies |
| `npm run dev` | Start dev server at `localhost:4321` |
| `npm run build` | Build to `./dist/` |
| `npm run preview` | Preview build locally |
| `npm run lint` | Run ESLint |
| `npm run format` | Run Prettier |

## Stack
- Astro (static output)
- React 19
- Tailwind CSS v4
- Lucide React icons
